RTIndustry User Manual

RTIndustry monitors your computer numerical control (CNC) machine or your PLC in real time: it counts parts, measures times and calculates production efficiency. At the top of every screen you will find the ? Help button: it takes you straight to the explanation of that screen.

1First steps

What RTIndustry does and how to use it every day, in five minutes.

  1. The machine works, RTIndustry records. The software reads the machine state (running, paused, in alarm…), the part counter and, if an energy meter is installed, the consumption. You do not need to do anything: the data arrives by itself.
  2. Work is organized in work orders (WO). A work order is a job: what to produce and how many parts. You create it on the Work orders screen and start it by dragging it to "In progress". If the machine starts without an active work order, RTIndustry creates one by itself ("Job started by the machine") so that no parts are lost.
  3. The operator uses the HMI. The Machine HMI screen is designed for whoever is at the machine: parts made, scrap, status and big buttons.
  4. The supervisor checks the results. Telemetry, OEE, Reports, Energy and Alarms show how the shift is going and how past periods went.
The software always keeps working, even if you close the browser: data collection is done by a Windows service that starts with the PC. The browser is only used to view and to give commands.

How to open it

  • Double-click the RTIndustry icon on the desktop, or
  • right-click the RTIndustry icon next to the Windows clock → Open dashboard, or
  • from another PC or tablet on the network: address http://PC-NAME-OR-IP:1880.

Several machines on the same PC

Each RTIndustry installation follows one machine. To connect more machines from the same PC or server, you install several instances: run the installer again, choose Install a new instance and give it a name (for example Mill2).

  • Each instance has its own folder (C:\RTIndustry-Mill2), Windows service (RTIndustry-Mill2), icon, data, backups and license.
  • The installer suggests free ports: the first additional instance answers on http://PC-NAME-OR-IP:1890, the second on :1900 and so on (you can see them on the Advanced page of the installer).
  • The instance name appears at the top next to the logo, on the sign-in page and in the browser tab title.
  • Each instance takes one seat of the license: with a multi-machine license you can use the same key in all of them.
  • To update them, run the installer and choose which instance to update; uninstalling one instance does not affect the others.

2Sign in

Everyone signs in with their own username and password: every operation is recorded under their name.

  1. Enter your Username and Password.
  2. Press Sign in. The work orders screen opens, or the page you were trying to open.

To leave: menu with your name at the top right → Sign out.

There are two types of account:

RoleWhat they can do
OperatorWork orders, HMI, telemetry, OEE, reports, energy, alarms, history. Cannot see Settings.
AdministratorEverything, plus Settings, license and Operators and activity log. The administrator account is created in the setup wizard.

Changing your password: menu with your name at the top right → My password. Enter your current password, then the new one twice (at least 8 characters).

Too many failed attempts: after 5 wrong passwords in a row for the same username, sign-in from that device is blocked for 30 seconds; each further error doubles the wait, up to 15 minutes. Other users can keep signing in. The message on the page tells you how long to wait.

Forgot your password? The administrator can set a new one from Operators and activity log. If the administrator has forgotten theirs, contact support.
Do not use a colleague's account and do not share your password: the activity log attributes every operation to the account it was made with.

3Setup wizard

It appears only the first time, right after installation: in six steps the software is ready.

  1. Company — company name (required), plant, department, machine name and time zone (for Italy Europe/Rome; daylight saving time is automatic).
  2. Machine — choose the connection type: OPC UA, FANUC, Heidenhain, Modbus TCP or Simulator (test data, no machine). Enter the IP address and press Test the connection: the green "Machine connected" box confirms that state and parts are coming in. If the machine is off you can go ahead and try again later from Settings.
  3. Shifts — start and end times of each shift (night shifts too).
  4. License — enter the key (format XXXX-XXXX-XXXX-XXXX) and press Activate license. Without a key a 30-day free trial starts. The box shows the result and the remaining days. If the company reaches the internet through a proxy, enter its address (and, if required, username and password) under Advanced options.
  5. Administrator — username and password (at least 8 characters) of the first administrator.
  6. Start — check the summary and press Start RTIndustry.
You can close the browser halfway through: when you open it again, the setup resumes from the step you had reached. With Back you return to the steps already completed.

4Finding your way around

  • Top bar: screen name, live machine status (color-coded), Live indicator (green = data coming in), ? Help button and user menu.
  • Round red button at the bottom right (+): opens the menu with all the screens.
  • Banner below the bar: appears only for license notices (see License and messages).
The Live indicator turns grey ("Offline") if the browser loses the connection with the RTIndustry PC: it reconnects by itself as soon as possible and no data is lost.

5Work orders

The job board: what needs to be done, what is in progress, what is finished.

What you see

Three columns: To do, In progress, Completed. Each card shows code, description, program, parts made and, if set, the due date (in red if overdue). The card being worked on updates by itself while the machine produces.

Creating a work order

  1. Press + New work order.
  2. Fill in at least the Description. Useful: Required quantity (for progress), Target time (s/part) (for performance), Due date, customer, order, part number, program, operator, notes.
  3. Press Save: the WO appears in "To do".

Starting, pausing, completing

  • Drag the card to the column you want: in "In progress" it starts, in "Completed" it closes. On a tablet, press and hold the card for a moment before dragging it.
  • The card in progress has quick buttons: Pause/Start, Scrap +1, Note, Complete.
  • The icons on the card open the HMI of that WO, editing or deletion (with confirmation).
Only one work order at a time is in progress. When you start another one, the previous one is paused automatically: parts are always assigned to the right WO.

6Machine HMI

The operator's screen at the machine: large, readable, usable on a tablet even with gloves on.

What you see

  • The work order in progress (or the one chosen from the list at the top), with due date, shift and machine status.
  • The progress ring: good parts compared with the required parts.
  • The cycle time deviation: how much the average part is slower (red) or faster (green) than the target time.
  • Any active alarm, highlighted.

What you can do

  • Scrap and Rework: with + and − you record the parts that are not good. Good parts are updated accordingly.
  • Work order status: buttons Start, Pause, Stop, Set-up, Rework, Maintenance, Cleaning, Fault, Complete. Giving the reason for a stop makes the reports more accurate.
  • Notes: write a note for the next shift and save it.

7Telemetry

How the current shift is going, updated every second.

  • Parts / hour: production rate of the shift.
  • Average cycle: running time divided by the parts produced.
  • OEE: overall efficiency of the shift (see OEE).
  • Shift energy: consumption since the start of the shift (if an energy meter is installed).
  • Chart of the power over the last hour, breakdown of the shift's time by state and CNC details (program, feed rate, tool…).

8OEE

The international indicator of a machine's efficiency: 100% means always producing, at the expected speed, with no scrap.

OEE = Availability × Performance × Quality

FactorQuestion it answersHow to improve it
AvailabilityFor how much of the shift did the machine work?Reduce downtime, long set-ups, waiting.
PerformanceDid it work at the expected speed?Set a realistic target time in the WO; reduce micro-stops.
QualityHow many parts are good?Record and reduce scrap and rework.

The page shows the shift OEE (circular gauge), the three factors, the weekly trend (Monday → Sunday) and the breakdown by shift for the day.

Performance is calculated only if the work order has a target time. Without one, it is 100%.

9Reports

The analysis of a past period: a week, a month, a specific shift.

  1. Choose the period and, if you like, the shift in the filters at the top.
  2. Read the summaries: Average OEE, Good parts, Scrap, Energy.
  3. Below you find the OEE day by day, the time distribution (production, pause, idle, stopped, alarm, maintenance, set-up), energy compared with production and the list of completed work orders.
  4. With Export CSV you download the data for Excel.

10Energy

How much the machine consumes and how much each part costs. Available if an energy meter is connected.

  • Real time: power drawn, shift energy, energy per part (Wh/part) and shift cost.
  • Period history: total energy and cost, daily average, day-by-day consumption and the trend of Wh per part.
The cost uses the energy price set in Settings › Services, energy and license (euros per kWh).

Connecting the energy meter

In Settings › Energy meter (Modbus) choose the meter model: the fields fill in by themselves and remain editable. For the IME CE4DT MID (Conto D4) the profile sets function FC4 (input register), unit ID 5, register 20592, type uint32, order ABCD and scale factor 100: you only need to enter the IP address. For other models choose Custom and copy register, data type and register order from the meter's manual.

The scale factor converts the value read into Wh (watt-hours), the unit RTIndustry uses for all its calculations: a meter that counts in kWh → factor 1000; in 0.1 kWh (like the IME) → 100; already in Wh → 1. Press Test reading: the result appears in Wh and in kWh and must match the total shown on the meter's display.

If you copy the factor 0.1 from the meter's notes (which reason in kWh), consumption comes out 1000 times too low: with the IME the right factor is 100.

11Alarms

How long the machine has been in alarm and for what causes.

  • Filters by period and shift.
  • Summaries: time in alarm, days with alarms, percentage of machine time, daily average.
  • Daily chart with the average line, breakdown by shift and event table: alarms longer than 5 minutes are highlighted.
  • Export CSV for analysis in Excel.
Only alarms lasting at least 5 seconds are recorded: momentary warnings do not distort the statistics.

12WO history

The complete archive of all work orders, including old ones.

  • Search by code, description, customer, part number…
  • Filter by status and sort by clicking a column header.
  • Export CSV downloads exactly the list you are looking at.

13Settings

The whole configuration of the software, reserved for the administrator. Changes apply immediately, without restarting anything.

At the top you find the connection status with the machine (ONLINE in green) and the Test connection button. With Try the changes before saving you check a new address or protocol without touching the one in use.

How parts are counted

RTIndustry counts parts in one of these ways, chosen in Settings › State and mode mapping · part counter:

  • Machine part counter (recommended): the software reads the control's counter (FANUC, SINUMERIK actParts, OPC UA variable or Modbus register).
  • At program end (part counter calculated from the program): when the machine does not provide a part counter, each direct transition from Running to Program end counts as one part. It is the default mode for Heidenhain (program end recognized by M30, M2/M02 or END PGM) and can be enabled on SINUMERIK with the acProg profile if actParts stays at 0. A reset after a stop (program aborted) does not count.
  • PLC counter (Heidenhain): if the NC program or the PLC keeps a counter, enter its path and the data access password; it works like the machine part counter.
Counting at program end reads the machine at intervals (usually every 5 seconds): if the operator restarts the cycle before the next reading, that part is not seen. With very short cycles or continuous cycles use the machine part counter or the PLC counter. When the software measures cycles shorter than three readings, the Short cycles warning appears in Settings.

SINUMERIK: the acProg (field-verified) profile uses the control's native nodes; the progStatus profile remains for controls that expose only that. With Detect the software suggests by itself the profile that responds.

Backup: every day RTIndustry saves a copy of the database in its own folder (last 7 days plus the last 4 Sundays). In Services, energy and license → Copy backups to another disk or network location you can set a second folder (for example D:\RTIndustry Backup or \\NAS\backup): this way, if the PC's disk fails, the history is not lost. Press Save, then Back up now: the message confirms whether the copy succeeded.

For a network folder: the RTIndustry service runs with the PC's system account, so the share must give write permission to the computer (in a domain: PC-NAME$) or the service must be installed with an account that has access to it. If in doubt, use a second disk or a USB stick that is always connected.
Deactivating the license frees the seat for another PC, but stops data collection on this one until you reactivate it.

14Operators and activity log

For the administrator only: personal operator accounts and the log of all operations (who did what and when).

Creating an operator account

  1. Menu + → Operators and activity log.
  2. Enter the Username (e.g. john.smith: letters, numbers, dot or hyphen), Full name and an Initial password of at least 8 characters.
  3. Press Create operator and give the password to the operator in person: they can change it from My password.

Managing accounts

ButtonEffect
EditChanges the full name or sets a new password (forgotten password).
Deactivate / ReactivateSuspends access: the operator is signed out immediately, even if they had the page open. Their activities remain in the log.
DeleteDeletes the account. The activities remain in the log. For a temporary absence, Deactivate is better.

Activity log

Lists, most recent first, every operation performed in the interface: sign-ins (including those rejected for a wrong password), sign-outs, creation, editing, moving, status changes, scrap and deletion of work orders, account management, saving of settings. For each one: date and time, user, activity, work order and details.

Filter by period (From / To), User and type of Activity, then press Filter. Export CSV downloads the filtered entries (up to 1000) to a file that opens in Excel.

The log cannot be edited or deleted from the interface. In the CSV file, date and time are in UTC (Italian time minus 1 hour in winter, minus 2 hours in summer).

16Using a tablet

From the menu with your name at the top right:

  • Tablet mode (large buttons): bigger buttons, suitable for touch and gloves.
  • Large text: characters easier to read from a distance.
  • Keep screen on and Full screen, where the device allows it.
In the tablet's browser you can use "Add to Home screen": RTIndustry then opens like an app, in full screen.

17Notification area icon

Next to the Windows clock there is the RTIndustry icon. Its color tells you at a glance whether everything is fine:

  • Green — service running and license valid.
  • Yellow — configuration to be completed or a warning (e.g. license about to expire).
  • Red — service stopped or license not active.

With a right-click: installed version, service and license status, Open dashboard, Settings, Stop service/Restart service, Show log.

With several instances on the same PC there are several icons, one per instance: the instance name appears in the menu and in the tooltip when you hover over it (for example RTIndustry Mill2). The icon is also used to open the attachment and program folders from Settings: if it is closed, it reopens at the next Windows sign-in.

18License and messages

The license is verified over the internet with the Site Manager and is managed from Settings (administrator only). If the license is not active, operators see the Service suspended page and must contact the administrator.

If the connection is missing, RTIndustry keeps working normally and retries by itself: the license remains valid for a few days even without internet (temporary offline operation notice), then the connection is needed again.

Several machines

Each installation (instance) takes one license seat. With 8 machines you need 8 seats: usually a single key with 8 seats, entered in all the instances. The Site Manager shows how many seats are in use.

Moving the license to another PC

On the old PC: Settings › Services, energy and license › Deactivate (frees the seat). On the new PC: install RTIndustry and enter the same key in the setup wizard. If the old PC no longer works, ask support to free the seat.

MessageWhat to do

Site Manager unreachable: temporary offline operationCheck the PC's internet connection. If the company uses a proxy, enter it in Settings › Services, energy and license. Work does not stop.

19Requirements, network and antivirus

The RTIndustry PC

  • Windows 10 (1809 or later) or Windows 11, 64-bit, 4 GB of RAM, 10 GB free; for several instances on the same PC allow about 100 MB of extra RAM for each machine (from 6 machines upwards 8 GB are recommended).
  • Always on: sleep = Never (while the PC is asleep no data is collected); Windows updates outside working shifts.
  • Correct date and time (shifts, reports and the license depend on the clock).
  • Connected to the network of both the machines and the tablets or PCs used to view the dashboard; internet (HTTPS to licenze.rtindustry.it) for the license.

Network ports

PortUse
1880Dashboard (browser of tablets and PCs). Additional instances use 1890, 1900… (see Several machines on the same PC).
1883MQTT for company systems (ERP, MES); additional instances 1893, 1903…
to the machinesFANUC 8193, OPC UA 4840, Heidenhain 19000, Modbus 502 (energy meter included).

The installation opens these ports in the Windows firewall by itself.

Antivirus with its own firewall (Avast, AVG, Kaspersky, ESET, Bitdefender, Norton…)

Many paid antivirus programs (and their trial versions) replace the Windows firewall: the rules opened by the installation no longer apply and the tablets cannot reach the dashboard, even though it opens normally on the PC. Some of them wrongly flag the RTIndustryTray.exe icon as suspicious (a false positive: it is a new program not yet known to the antivirus).

In the antivirus settings:

  • Exceptions / exclusions: add the C:\RTIndustry folder (and the C:\RTIndustry-… folder of each instance).
  • Firewall: allow incoming connections to the program C:\RTIndustry\node\node.exe (one per instance), or set the shop-floor network as private/trusted.
  • If the icon has been quarantined, restore it from the antivirus quarantine and restart the PC.
Always test from the tablet: open http://PC-NAME-OR-IP:1880. The C:\RTIndustry\strumenti\Verifica-RTIndustry.bat tool reports whether a third-party firewall is present on the PC.

20Troubleshooting

The machine shows "Off or unreachable"

  • Check that the machine is switched on and the network cable is connected.
  • In Settings press Test connection: the message tells you what is wrong (address, port, credentials).

The part count does not increase

  • Check that there is a work order In progress and that the machine is Running.
  • In Settings › State and mode mapping · part counter check the part counter variable.
  • If the machine's part counter does not move (for example it stays at 0), enable counting at program end: see How parts are counted.

The page does not open

  • Look at the notification area icon: if it is red, right-click → Restart service.
  • From another PC: check that you are using the right address and port 1880 (additional instances: 1890, 1900…).

The dashboard opens on the PC but not on the tablets

  • It is almost always the antivirus firewall: see Antivirus with its own firewall.
  • Check that the tablet and the PC are on the same network (or that the company network allows the connection).

The antivirus flags RTIndustry

  • It is a false positive: add the exceptions described in Antivirus with its own firewall and restore the file from quarantine. Data collection (the service) continues even without the icon.

The "Short cycles" warning appears in Settings

  • With counting at program end some parts may be missed because the cycle is shorter than three readings: use the machine part counter or a PLC counter (see How parts are counted).

Consumption looks 10, 100 or 1000 times wrong

  • The energy meter scale factor is not right: the value must come out in Wh. See Connecting the energy meter and compare the reading with the meter's display.

Error codes

CodeMeaning and solution
RTI-E001The software does not start on this PC (folder copied from another PC, or PC name changed or Windows reinstalled). Reinstall RTIndustry: the data is kept.
RTI-E011Port 1880 is taken by another program (for example the previous version). Close the other program or change the port.

22Support

For questions or problems contact the technician or reseller who installed RTIndustry, or write to assistenza@rtindustry.it.

When you ask for support, attach the diagnostics file: Settings › Export diagnostics button at the top. It contains version, software status and the latest operating messages, without passwords.

If the software does not open, attach instead the report of C:\RTIndustry\strumenti\Verifica-RTIndustry.bat (double-click it: it checks the PC, the network and the connection to the machine).
